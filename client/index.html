About GifHub

GifHub is an open-source hub for discovering, sharing, and saving the funniest GIFs across the web.

Our Mission

We believe humor connects people. GifHub makes it simple to search, collect, and enjoy GIFs with friends and communities.

Features

  • 🔍 Powerful search powered by Giphy API
  • ❤️ Save favorites with one click
  • 👤 Personalized profile with avatar upload
  • 📱 Responsive design for desktop and mobile

Open Source

GifHub is a community-driven project. Contributions are welcome to improve features, fix bugs, and expand functionality.
